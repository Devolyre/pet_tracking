# KAZEROS — Pet Tracking

Aion 2 pet routes and collection tracker, in Russian and English.

## Publishing
Enable GitHub Pages from the main branch, root directory. The site uses relative asset paths and is ready for `/pet_tracking/`.

## Updating
Edit HTML, CSS, JavaScript or assets and push to main. GitHub Pages republishes the site.

Progress is stored per browser. Use Export / Import to transfer progress between domains or devices.

Art by Blue Pineapple. Data and image credits are listed in the site footer.
